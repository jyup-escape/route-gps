# Route GPS 1.2.0 — 明るくシンプルな操作画面

## Brief / reference lock

Android向けRoute GPS。Google/GPXの道筋を取り込み、確認して疑似GPSを再生する。ユーザー指定は「明るい系・シンプルに」。既存の白・緑の配色を主参照とし、ReferoのTypography、Color、Craft Details、Anti-AI-Slop資料を補助参照に固定する。Refero Stylesは3方向を検索したがNO_SUBSCRIPTIONで取得できなかった。存在しない参考画面を根拠にはしない。

主方向：白いキャンバス、黒に近い文字、緑の主要操作、道路形状の大きな確認領域。単一のシステムサンセリフ、13/15/18/24/32pxの5段階、8px単位の間隔。カード・影・装飾グラデーションは増やさず、区切り線で整理する。取得中・未読込・停止・再生・エラーを色と文章で伝える。地図タイルのない形状表示を地図と呼ばない。

| 決定 | 参照と役割 | 理由 |
| --- | --- | --- |
| 白/灰色の面、#006B58の主要操作・ルート | 既存Route GPS、ユーザーの明るい画面指定、Colorの役割分離 | ブランドを維持し、主操作を見つけやすくする |
| 再生・取り込み・設定の3画面 | Androidの主要ナビゲーション指針 | 長いフォームから再生操作を探す負担を減らす |
| 地点数・距離・巡航速度での目安を別の数字として表示 | 既存ルート情報、Typographyのスキャン重視 | 重要情報を短時間で読める |
| 加減速・ゆらぎ・信号待ちを設定画面へ | ユーザーのシンプルさ指定、Craft Detailsのフォーム整理 | 毎回必要な操作を優先する |
| 48px以上の操作領域と常設ラベル | Android Accessibility、Craft Details | タップと読み上げ、拡大に対応 |
| ルート形状を実データから描画 | 既存プレビュー、ユーザーの道筋一致要求 | 装飾地図や架空の道路を表示しない |
| 全座標ではなく先頭/末尾の短い入力 | 1.1.7のOOM修正 | 表示変更でクラッシュ対策を戻さない |

参考：
- https://developer.android.com/design/ui/mobile/guides/layout-and-content/layout-and-nav-patterns
- https://developer.android.com/guide/topics/ui/accessibility/views/apps-views

## Implementation / QA target

描画対象はAPK内のHTML/CSS/JS。AndroidのGPS、通信、ファイル選択、保存は既存Java処理を使用する。WebViewはアプリ内の3ファイルだけを返す専用オリジンで動かし、外部ページ・任意ファイル・任意操作をブリッジへ渡せないようにする。外部ライブラリやCDNを追加しない。

ブラウザでも同じassetsをレンダリングし、320px/400px/横向き幅でレイアウトとタブ、入力、取得中・再生中・エラーを確認する。ブラウザの表示検証とAndroid実機での通信・GPS・ファイル選択の通し検証は区別して報告する。

## QA結果

- C1の567地点GPXを表示データとして使用し、320×740、400×880、1120×700で横方向のはみ出しなし。
- 再生→一時停止→再開/停止、3画面の切替、設定値の保持、取得中の入力/ボタン無効化、エラー表示を確認。ナビゲーションの操作領域は56px。
- 本番と同じui.jsを構文検証。ブラウザのエラーログなし。APKにindex.html/ui.css/ui.jsの3資産が含まれることを確認。
- 解消したP2：再生操作が下部ナビに隠れやすかったため、形状領域と余白を短くし、再生中は形状領域をさらに縮小。入力境界とOFFスイッチのコントラストも補正。
- ブラウザの状態変化は検証用ホストで模擬。Android実機でGPS・通信・ファイル選択を通しての操作は未検証であり、ブラウザの確認を実機検証と呼ばない。

## 次の機能候補

保存ルートの一覧と名前付け、速度/加減速プリセット、停止位置からの再開・開始位置指定、GPXの区間結合/切り出しを優先候補とする。本リリースで実装済みなのは画面整理と時間/進捗表示のみ。
