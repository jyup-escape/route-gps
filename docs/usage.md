# Route GPS 1.1.4

徒歩ルートを疑似GPSとして再生するAndroid 8.0以上向けアプリです。電車・時刻表対応は開発中です。

## インストールと設定

APKをAndroidへインストールしてください。以前と同じ署名鍵を使用しているため上書き更新できます。Androidの開発者向けオプションで「仮の現在地情報アプリ」をRoute GPSに設定し、アプリの正確な位置情報を許可します。

## Google MapsからGPXを作成

1. Google Mapsで出発地・経由地・目的地を指定した経路を作ります。「現在地」は具体的な場所に変更してください。
2. 経路リンクをコピーしてアプリへ貼り付けるか、共有メニューでRoute GPSを選びます。
3. 「リンクから徒歩ルートを作成」を押します。場所名の検索候補が出た場合は正しい場所を選んでください。
4. 出発地と目的地、ルート形状・距離を確認し、「このルートをGPXで保存」で保存先を選びます。作成したルートをそのまま再生することもできます。

Google MapsのURLから地点を取り込み、OpenStreetMapの徒歩ルートを再計算します。Google Mapsで表示された道順・選択した代替ルート・所要時間は引き継ぎません。Googleの経路形状をそのままGPXとして抽出する機能ではありません。

対応形式はorigin/destination/waypoints形式、通常の/maps/dir/形式、旧saddr/daddr形式と既知のGoogle Maps短縮リンクです。場所だけの共有リンクや表示中心だけのURLには出発地・目的地がないため対応しません。展開に失敗した場合はブラウザで開いた後の長い経路URLを使ってください。経由地は道路検索と同じ2地点以上です。

短縮リンクはGoogleへ、場所名はNominatimへ、座標はOSRMへ送信します。場所名検索は明示操作時のみ、秒あたり1回以下で結果をキャッシュします。位置情報を検索欄に自動入力しません。

## GPXと座標

- GPXの地点数・ファイルサイズ・距離に固定上限はありません（端末のメモリ・保存容量の範囲内）。1つのtrksegまたはrteを読み込めます。トラックとルートが両方ある場合はトラックを優先します。DTDは使用できません。
- GPXの形状を保持します。通れる道に沿っているかは作成元で確認してください。記録時刻・速度・標高は使いません。
- 座標から作成する場合は緯度,経度を1行ずつ2地点以上入力し、「道に沿う徒歩ルートを作成」を押します。生成後は細かい道路形状に置き換わります。
- 周回する場合は作成前にONにしてください。終点から始点への道路ルートも生成します。
- 道路検索は25経由地ずつ重複する境界点で接続し、信号取得は最大10km・256座標の区間ごとに進捗を表示します。これらは1回の通信の大きさで、ルート全体の上限ではありません。20kmより長いルートでは自動の信号取得を省略します。作成後に「このルートの信号を取得・再試行」で全区間を取得できます。区間の総数に制限はありませんが、公開サーバーの負荷を抑えるため通信間に2秒待ちます。
- プレビューは道路背景のない形状図です。OSMのデータによって検索結果は変わります。

## 移動設定

巡航速度は0.1km/h以上、加速度・減速度は0より大きい値、速度の揺らぎ・信号待ち秒数は0以上で、設定の上限はありません。有限値と、計算結果が数値の表現範囲に収まる設定を使います。確率は0〜100%、待ち時間は最小≦最大です。

揺らぎが100%を超えて負の目標速度になった場合は0に補正します。6〜14秒ごとに目標を更新し、曲がり角で減速します。加減速や停止点があるため、短い区間では設定速度に達しない場合があります。

信号はOSMに登録された位置を対応づけ、赤に当たるかは通過ごとに抽選します。実際の現在色とは連動しません。信号取得に失敗した場合は再試行または距離の手入力ができます。

## 再生

作成・読込後に再生します。一時停止・停止は減速してから行います。終点では位置を保持し、停止すると疑似GPSを解除します。設定変更は停止後に行います。他アプリに反映されるかは、そのアプリとAndroid環境の疑似GPS対応によります。

## 配布と検証

配布はバージョン別のAPKとビルド元ソースZIPのみです。署名鍵、SDK/JDK、設定ツールは同梱しません。ソースをビルドする場合はWindowsで`python setup_tools.py`、`python build.py`を実行します。

ルート・移動シミュレーション、URL解析、30万1地点・約4万kmのGPX往復、補間・再生計算、50MB超のストリーム読込、1万1件の信号・不正XMLをホスト上でテストし、Androidコンパイル・APK署名を検証しています。Google Maps形式のURLからパリのOSRM徒歩ルートを実通信で作成し、GPX往復とNominatimの場所候補取得も確認しました。Android画面の操作、共有・保存・疑似GPS再生の実機検証は未完了です。

道路生成：OSRM / FOSSGIS。地図データ：© OpenStreetMap contributors（ODbL）。場所名検索：Nominatim。

1.1.4では共有経路URLに地点座標が含まれる場合、対応する全地点が確認できればその座標を使います。座標がない場合は場所名を検索し、混在する住所で見つからない場合は施設名のみで再検索して候補を確認します。

地球一周相当の距離をGPXで読み込み、計算できることをホスト上で確認しています。Google Mapsからの道路再検索はOSRMのサービス制約と道路網の接続に依存します。海を越える徒歩ルートなど、道路として接続していない区間を自動生成することはできません。プレビューのみ最大4096点に間引き、GPX保存と再生には全地点を使用します。
